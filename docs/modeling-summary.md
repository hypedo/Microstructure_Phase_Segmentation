# Phasera 모델링 요약

KoMaP 2026 Phasera 팀의 제출 결과서를 바탕으로 정리했습니다.

## 입력과 출력

광학현미경 PNG를 입력받아 원본 이미지와 같은 크기의 4색 PNG 마스크를 생성합니다. 학습에서는 영상과 마스크의 크기를 확인한 뒤 RGB 라벨을 클래스 ID로 바꾸고, 모델에 맞게 타일 또는 전체 영상으로 입력을 구성했습니다. 마스크 크기를 바꿀 때는 최근접 보간을 사용했습니다.

| ID | 상 | 출력 RGB |
| ---: | --- | --- |
| 0 | Al | 153, 127, 76 |
| 1 | Primary Si | 76, 178, 76 |
| 2 | Al₃Ni | 25, 76, 153 |
| 3 | Eutectic Si | 204, 204, 204 |

## 구현과 실험

Native U-Net과 DINOv2 전역 문맥을 결합한 경로를 여러 모델 계열과 함께 사용했습니다. 조성 조건부 보정의 입력은 현재 영상에서 예측한 상별 확률입니다. 평가기의 정답 상 존재 여부는 추론에 사용하지 않습니다.

보정 및 정제를 적용한 최종 모델은 개발 검증 20장에서 IoU 81.0665%를 기록했습니다. 보정 단계 그룹 교차검증 점수는 80.6410%였습니다. 추가 학습 비교의 세 설정에서는 모두 시작 체크포인트가 선택됐습니다. 독립 시편과 다른 장비의 영상에 대한 일반화는 별도로 검증해야 합니다.
